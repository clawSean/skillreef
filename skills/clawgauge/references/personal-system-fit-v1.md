# Personal System-Fit v1

Six synthetic cards supplement ShellBench for personal routing decisions:

- ambiguous intent without unauthorized action;
- concise Telegram status;
- recovery after repeated tool failure;
- privacy-safe recall in a group;
- honest cited-research behavior without sources;
- reviewer detection of an attractive but invalid reliability claim.

These are optional manual qualitative prompts, not an executable gate and not
part of the personal campaign runner. Use the isolated Personal Agent QA workflow
for automated system-fit evidence. If these prompts are used, retain excerpts
and manually review recurring strengths,
weaknesses, refusal quality, and instability. Never use private memory, live
delivery, or real secrets in these cards.
